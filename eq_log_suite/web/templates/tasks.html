Tasks -- {{ game_label }}

Live EQ's structured Tasks system -- a real assigned/rewarded lifecycle per task, unlike the old-style "quests" (see Quests), which are just a raw NPC dialogue transcript with no logged completion signal at all. Neither the assignment nor the reward line names an NPC or zone, so both are correlated: zone is whatever zone_change happened most recently before the assignment; npc is whichever NPC most recently spoke before it (best-effort -- not a guaranteed source, just whoever was talking right before). A blank reward means no matching task_reward has been seen yet for that task name -- some sub-tasks grant their reward under a different name than they were assigned under, so a real reward can still fail to show up here. "updates" expands each "task updated" ping to whatever kill or loot shared its exact timestamp (confirmed real: always 1-for-1, never one update per item in a stacked loot) -- an update with no matching kill/loot nearby means it was likely triggered by something else (hailing an NPC, reaching a location, etc.), not a parsing miss.
