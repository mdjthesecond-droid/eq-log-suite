Each capture is an item-window screenshot OCR'd automatically by item_capture_watcher. The OCR text is a starting point, not the truth -- read the screenshot yourself and correct the item name/tier/exaltations/stats before confirming. Tier and exaltations are tracked as their own fields because they change over time (an item's tier can level up, exaltation slots can fill in) -- every confirm adds a new snapshot rather than overwriting, see /items and each item's history link. Only equippable items have a Tier at all -- leave it blank if the item doesn't; a "+N" in the item's own name should match its tier, and a mismatch between the two is flagged below since OCR likely misread one of them. Item name and exaltation slot fields autocomplete against already-confirmed item names -- prefer picking the existing spelling over retyping a fresh OCR guess (OCR spells the same name differently across captures often enough that this matters for keeping them joinable). Confirming an item also clears its capture from this queue -- if a screenshot happens to have more than one item's tooltip in it (rare now that captures are single-item), submit every block's form below before confirming any of them, since the page navigates away on the first submit. Made a mistake after confirming? Every item's own page has an Edit button. Reject discards the capture entirely (blurry shot, wrong window, irrelevant screenshot) without adding anything to the catalog.
